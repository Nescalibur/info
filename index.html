PROTOCOLS

MODE A: POWER
MVC / MECHANIC IMPULSE

Измерение пикового усилия и способности удерживать нагрузку (Anaerobic Capacity). Оценка рекрутирования двигательных единиц.

MODE B: SPEED
LATENCY / iRFD / EXPLOSIVE IMPULSE

Тест реакции из преднатяга. Анализ взрывного импульса (Explosive Drive) в окне 0–100мс. Валидно для 80Гц.

MODE C: VOID
NORMALIZED RELAXATION RATE

Уникальная метрика. Скорость активного расслабления мышц. Главный маркер утомления ЦНС и эффективности восстановления.
